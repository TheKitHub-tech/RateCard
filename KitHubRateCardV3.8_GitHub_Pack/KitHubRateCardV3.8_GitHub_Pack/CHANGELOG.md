# Changelog

All notable changes to the Kit Hub External Hire Rate Card should be recorded here.

## [3.8] - 2026-07-29

### Added

- Client name field in the basket.
- Company or production field in the basket.
- Client email address field.
- Client phone number field.
- Contact details included in the exported Excel request list.
- Contact details formatted so Quote Builder V2.7 and later can import them automatically.
- Privacy notice explaining that the request list is generated on the user's device.

### Changed

- On-screen Request List terminology changed to Basket.
- Exported spreadsheet remains named and labelled as a Request List.
- Request list filename now uses company or production and client name where available.
- Final workflow downloads the request list and opens a prepared email to the Kit Hub.

### Known limitation

- Browser security prevents a standard `mailto:` link from attaching the downloaded Excel file automatically.

## Earlier prototype history

Earlier releases developed search, filtering, hire-period calculations, spreadsheet import, basket management, Excel export, Middlesex University branding, mobile layouts and asset information popovers. Detailed historical notes are retained in project working records rather than reproduced in full here.
