# Internal Quote Builder

## Current version

The current internal tool is `KitHubQuoteBuilderV3.2.html`.

It is a staff tool and is not published from the public Netlify `site/` folder. The file is deliberately not included in this public repository pack.

## Current compatibility

V3.2 is compatible with the combined Booking Request generated by the current rate-card family. The compatibility regression covers:

- equipment-only and mixed equipment/room imports;
- production/client name, contact and company fields;
- equipment collection and return dates and times;
- Friday-to-Monday weekend booking at two chargeable days;
- equipment base rates and calculated unit prices;
- room charge, mandatory support and line total preservation;
- optional/custom assets;
- quote PDF generation;
- embedded editable quote data;
- reopening a quote PDF;
- legacy Booking Request import fallback.

V4.30 changed one equipment data row and description but did not change the Booking Request schema. The V3.2 compatibility suite has therefore been rerun against V4.30 before release packaging.

## Pricing ownership

For imported room lines, the public rate card's calculated room charge and mandatory support are authoritative. The Quote Builder should not silently recalculate them using a different formula.

Equipment dates can be edited by staff in the Quote Builder. Equipment prices then recalculate using the same duration and weekend rules. Locked imported room prices remain unchanged unless deliberately edited through the appropriate staff workflow.

## Integration gate

Rerun the end-to-end compatibility test whenever the public Booking Request changes any:

- metadata label;
- worksheet name;
- column heading;
- item-type value;
- date/time representation;
- pricing-basis text;
- room-support field;
- production/client field;
- export filename convention.

Do not publish a schema-changing rate-card release on the assumption that the Quote Builder will accept it.

## Separation rule

Keep the Quote Builder internal unless an approved decision changes its audience and hosting. It may contain staff-only workflows and should not be linked from the public rate card.
