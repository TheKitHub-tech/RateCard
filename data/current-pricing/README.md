# Current Pricing

This folder contains human-readable pricing snapshots for the Kit Hub External Hire Rate Card.

## V5.0

`Kit_Hub_Current_Pricing_V5.0.xlsx` contains the equipment, room and technical support pricing extracted directly from the current V5.0 application.

The V5.0 website does not connect to this workbook or to a live pricing database. The live pricing used by V5.0 is currently stored inside `site/index.html`.

When an approved price changes, the website pricing and this reference workbook should be updated together.

Do not infer or invent missing prices. Use the latest approved pricing information from the Kit Hub.
